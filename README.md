# Earth Simulation Game

A detailed 2D strategy simulation game featuring a realistic Earth model, resource management, and civilization development.

## Features (Phase 1)
- Interactive 2D Earth visualization with zoom and pan
- Dynamic weather systems and climate patterns
- Resource economy (Food, Water, Energy, Materials, Population, Technology)
- Civilization management with unique traits
- Natural disasters and global events

## Setup Instructions
1. Ensure you have Python 3.8+ installed
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run the game:
   ```
   python main.py
   ```

## Controls
- Left Mouse Button: Pan
- Mouse Wheel: Zoom
- ESC: Exit game

Currently in Phase 1 of development. See the project documentation for planned features and roadmap.
